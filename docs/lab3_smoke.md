# Лабораторная работа №3

## Функциональное тестирование

Выбранный вид — smoke-тестирование. Цель — быстро проверить запуск приложения и основные действия перед дальнейшим тестированием.

## Условия проверки

- Windows 11, Python 3.12.14, Tk 8.6.
- Запуск из каталога проекта: `python main.py`.
- Проверка через графический интерфейс с визуальным сравнением результатов.
- В записи матриц точка с запятой обозначает новую строку. В приложении строки вводятся с новой строки.

## Сценарии и результаты

| № | Действия | Ожидаемый результат | Фактический результат | Итог |
|---|---|---|---|---|
| SM-01 | Запустить приложение | Открывается окно с полями A, B, результата и шестью кнопками | Окно открылось, поля пустые, кнопки отображаются | Пройден |
| SM-02 | Ввести A = [1 2; 3 4], B = [5 6; 7 8], выполнить A + B | [6 8; 10 12] | [6.0 8.0; 10.0 12.0] | Пройден |
| SM-03 | С теми же матрицами выполнить A × B | [19 22; 43 50] | [19.0 22.0; 43.0 50.0] | Пройден |
| SM-04 | Заменить B на [5 6], выполнить A × B | Сообщение «Количество столбцов первой матрицы должно совпадать с количеством строк второй.» | Получено указанное сообщение | Пройден |
| SM-05 | Закрыть сообщение и выполнить очистку | Поля A, B и результата пустые | Все три поля очищены | Пройден |

Для SM-02 ожидаемые значения вычислены поэлементным сложением. Для SM-03, например, первый элемент равен 1 × 5 + 2 × 7 = 19. Остальные элементы рассчитаны аналогично.

После ошибки в SM-04 предыдущий результат остаётся в поле до очистки. Нового результата при ошибке не получено. В SM-05 проверено, что приложение продолжает реагировать на действия после закрытия сообщения.

## Вывод

Все пять smoke-проверок пройдены. Запуск, выбранные вычисления, обработка несовместимых размеров и очистка работают на указанных данных. Дефекты в этих сценариях не обнаружены, исправления не потребовались. Полная проверка всех функций и входных данных в этот набор не входит.
