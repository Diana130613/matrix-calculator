# Лабораторная работа 2

Для демонстрации выбрано автоматизированное тестирование. Используется
стандартный модуль Python `unittest`, дополнительные библиотеки не нужны.
Тесты находятся в `tests/test_gui.py`.

## Как устроены проверки

Перед каждым тестом создаётся отдельный экземпляр приложения Tkinter.
Окно скрывается, в поля вводятся A = [1 2; 3 4] и B = [5 6; 7 8].
Точка с запятой обозначает новую строку. Тест вызывает команду кнопки
через `invoke()` и сравнивает текст результата с заранее рассчитанным.
После теста окно уничтожается.

| Тест | Проверка | Ожидаемый и полученный результат |
|---|---|---|
| 01 | Сложение | [6.0 8.0; 10.0 12.0] |
| 02 | Вычитание | [-4.0 -4.0; -4.0 -4.0] |
| 03 | Умножение | [19.0 22.0; 43.0 50.0] |
| 04 | Определитель A | -2.0 |
| 05 | Транспонирование A | [1.0 3.0; 2.0 4.0] |
| 06 | A = [1 x; 3 4], сложение | Ошибка «Матрица должна содержать только числа.», результат пуст |
| 07 | Сложение, затем очистка | Поля A, B и результата пусты |

Сообщение `messagebox.showerror` перехватывается через `unittest.mock`,
чтобы не требовалось закрывать диалог вручную. При неправильном вводе
проверяются заголовок и текст сообщения. При корректных данных
сообщений об ошибках быть не должно. Необработанные ошибки команд кнопок
также приводят к провалу проверки.

## Запуск и результат

Нужен Python 3 с Tkinter и доступная графическая сессия.
Выполните из каталога `matrix-calculator`:

```bash
python -m unittest tests.test_gui -v
```

Проверка 21 октября 2026 года в Windows, Python 3.12, Tk 8.6:
все семь тестов пройдены, итог `Ran 7 tests`, `OK`.
Полный набор также пройден: 15 тестов, без ошибок и провалов.

```bash
python -m unittest discover -v
```

Вывод отображается в консоли. Отдельный запускатель и JSON с результатами
не требуются. Для повторной проверки достаточно той же команды.

Сценарии проверяют поля, команды кнопок и результат. Внешний вид диалогов,
расположение элементов и действия мышью ими не проверяются. Результат
относится к выбранным данным.
