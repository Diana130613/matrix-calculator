# Матричный калькулятор

Приложение на Python и Tkinter для сложения, вычитания, умножения,
транспонирования матриц и вычисления определителя.

Требуется Python 3 с Tkinter. Дополнительные библиотеки не нужны.

Запуск:

```bash
python main.py
```

Тесты:

```bash
python -m unittest discover -v
```

Диаграмма классов: [docs/uml.puml](docs/uml.puml).
