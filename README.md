# Матричный калькулятор

Учебное приложение, разработанное в рамках лабораторных работ по дисциплине «Тестирование и отладка программного обеспечения».

## Назначение

Приложение предназначено для выполнения основных операций над матрицами.

## Возможности

Программа поддерживает следующие операции:

* сложение матриц;
* вычитание матриц;
* умножение матриц;
* транспонирование матрицы;
* вычисление определителя квадратной матрицы;
* обработку некорректных входных данных.

## Технологии

* Python 3
* Tkinter
* unittest
* Git

## Запуск приложения

Для запуска приложения необходимо выполнить:

```bash
python main.py
```

## Запуск тестов

Для запуска автоматических тестов:

```bash
python -m unittest discover
```

Реализовано 15 автоматических тестов: 8 проверок вычислительных классов и 7 сценариев через виджеты Tkinter. Для запуска сценариев интерфейса нужна доступная графическая сессия.

## Лабораторная работа №1

В рамках первой лабораторной работы приложение используется для демонстрации тестирования методом «чёрного ящика».

Основные проверяемые функции:

1. Сложение матриц.
2. Вычитание матриц.
3. Умножение матриц.
4. Транспонирование матрицы.
5. Вычисление определителя.
6. Обработка матриц несовместимых размеров.
7. Обработка некорректного умножения матриц.
8. Обработка попытки вычисления определителя неквадратной матрицы.

## Лабораторная работа №2

Автоматизированное тестирование с помощью стандартного модуля `unittest`.
В `tests/test_gui.py` находятся семь обычных тестовых методов: сложение,
вычитание, умножение, определитель, транспонирование, буква вместо числа
и очистка полей. Каждый тест создаёт приложение, заполняет поля, вызывает
кнопку через `invoke()` и сравнивает результат с ожидаемым.

Из каталога проекта выполните:

```bash
python -m unittest tests.test_gui -v
```

Результат выводится в консоль: `Ran 7 tests`, `OK`. Отдельный запускатель
и дополнительные библиотеки не требуются. Нужен Python с Tkinter
и доступная графическая сессия.

Вызов `messagebox.showerror` перехватывается через `unittest.mock`, чтобы
тесты не ожидали закрытия диалога. Проверяется текст ошибки;
внешний вид диалога и действия мышью не проверяются.

[Сценарии и результаты](docs/lab2_automation.md). [Отчёт](docs/lab2_report.docx).

## Лабораторная работа №3

Выполнено функциональное тестирование методом smoke-тестирования. Через интерфейс проверены запуск приложения, сложение, умножение, сообщение о несовместимых размерах и очистка после ошибки. Все пять проверок пройдены. [Сценарии и результаты](docs/lab3_smoke.md).
