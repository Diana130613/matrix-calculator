# Матричный калькулятор

Учебное приложение, разработанное в рамках лабораторных работ по дисциплине «Тестирование и отладка программного обеспечения».

## Назначение

Приложение предназначено для выполнения основных операций над матрицами.

## Возможности

Программа поддерживает следующие операции:

* сложение матриц;
* вычитание матриц;
* умножение матриц;
* транспонирование матрицы;
* вычисление определителя квадратной матрицы;
* обработку некорректных входных данных.

## Технологии

* Python 3
* Tkinter
* unittest
* Git

## Запуск приложения

Для запуска приложения необходимо выполнить:

```bash
python main.py
```

## Запуск тестов

Для запуска автоматических тестов:

```bash
python -m unittest discover
```

Реализовано 26 автоматических тестов: 8 проверок вычислительных классов и 18 сценариев через виджеты Tkinter. Для запуска сценариев интерфейса нужна доступная графическая сессия.

## Лабораторная работа №1

В рамках первой лабораторной работы приложение используется для демонстрации тестирования методом «чёрного ящика».

Основные проверяемые функции:

1. Сложение матриц.
2. Вычитание матриц.
3. Умножение матриц.
4. Транспонирование матрицы.
5. Вычисление определителя.
6. Обработка матриц несовместимых размеров.
7. Обработка некорректного умножения матриц.
8. Обработка попытки вычисления определителя неквадратной матрицы.

## Лабораторная работа №2

Автоматизированное тестирование реализовано в `tests/test_gui.py`. Сценарии создают настоящее приложение Tkinter, заполняют поля и вызывают команды кнопок через `invoke()`. Проверяются результаты вычислений, точные сообщения об ошибках, сохранность ввода, очистка и работа после исправления ошибки.

Запуск 18 сценариев и сохранение протокола:

```bash
python run_lab2.py
```

Протокол сохраняется в `artifacts/lab2/test-run.txt`, статусы и фактические значения — в `artifacts/lab2/results.json`. Чтобы открыть окно протокола и калькулятор после запуска:

```bash
python run_lab2.py --show-results
```

Ожидаемые результаты заданы в сценариях заранее. Сообщения `messagebox.showerror` перехватываются с помощью `unittest.mock`: проверяются заголовок, текст и количество вызовов. Внешний вид и закрытие диалога, координаты кликов и расположение элементов этими сценариями не проверяются.

## Лабораторная работа №3

Выполнено функциональное тестирование методом smoke-тестирования. Через интерфейс проверены запуск приложения, сложение, умножение, сообщение о несовместимых размерах и очистка после ошибки. Все пять проверок пройдены. [Сценарии и результаты](docs/lab3_smoke.md).
